FAQ

The questions everyone asks, answered.

⚡ In 30 seconds

Can't find an answer? Reach out to Jake at jake@aptera.us.

Which mode should I use — Chat, Co-Work, or Code?

Use Chat for quick thinking, drafting, and one-off questions—no setup needed. Co-Work is your jam when you need Claude to see your files and folders; drop in a messy spreadsheet or doc and ask Claude to clean it up or analyze it. Code gives Claude full access to your machine and development environment when you’re building or debugging. Each has a different vibe—check out The Three Modes for the full breakdown with real examples.

Is my data used to train the model?

No. Aptera uses an enterprise account, so nothing you ask Claude—no conversations, files, or context—goes into training new models. Your data stays yours. That said, treat it like any internal tool: don’t paste passwords or secrets you wouldn’t share in an email. See Safety & Data for the full data policy.

Why didn't my Schedule or Routine run overnight?

Schedules and Routines need your computer to be on and the Claude app running. If you shut down your machine or closed the app, the scheduled task waits until you boot back up and launch Claude again. Pro tip: leave your machine running and Claude open if you want overnight automation. Check your routine’s history in the Claude Code sidebar to see if it ran or what went wrong.

Claude gave me a wrong answer — what do I do?

Claude is a draft partner, not an oracle—it can hallucinate or miss details. Always verify important facts with a second source and iterate. Tell Claude what went wrong (“That link doesn’t work” or “That’s not what the policy says”) and ask it to try again. If it keeps failing, start fresh or break the problem into smaller steps. And if you spot a real mistake, flag it to Jake so we can learn what Claude struggles with.

Why does Claude seem to forget things mid-conversation?

Within a single chat, Claude holds everything in its context window — its short-term working memory for that session. It’s large but finite, so in very long conversations (lots of back-and-forth, big documents, many files) it fills up and Claude’s recall of earlier details can start to slip. Quick fixes: start a fresh chat when you switch topics, ask Claude to summarize the work so far before continuing, or save important details to a document. For work that spans many sessions, lean on Memory and Projects so Claude remembers across chats. See the Context Window and Memory & Projects lessons for the full picture.

Which model should I pick — Haiku, Sonnet, Opus, or Fable?

Haiku is fastest and cheapest—great for quick analysis, summarization, and routine tasks. Sonnet is the all-rounder: smart enough for complex work but still fast and cost-effective. Opus is the heavyweight: best for really hard problems (deep reasoning, code review, tricky analysis). Fable is the frontier model—for the biggest multi-step jobs and for orchestrating teams of cheaper models. Start with Sonnet and escalate only when the job demands it. See Tokenomics for a side-by-side comparison and when each pays for itself.

Can Claude access my files?

It depends on the mode. Chat: Only what you paste or upload. Co-Work: Only folders you explicitly grant access to—you stay in control. Code: Full access to your machine and all your local files. No mode touches your email, browsers, or anything not on your local drive or the folder you gave permission for. Think of it like sharing a folder with a coworker: you control what’s in there.

How do I get a tool like NetSuite or Slack connected?

We have plugins and connectors for the big tools—Slack, NetSuite, Jira, Salesforce, and more. To request a new connector or set one up, ping Jake at jake@aptera.us. He’ll either plug it in directly or help you configure one if Aptera’s tech stack supports it. Check Connectors & Skills for the full list of what’s already wired up.

Why won't an HTML file open properly from SharePoint?

SharePoint sandboxes scripts inside HTML files for security, which breaks most interactive pages. If you need an HTML dashboard or tool, host it on GitHub Pages instead—that’s why this training site lives on GitHub rather than SharePoint. It’s a limitation of SharePoint’s security model, not a Claude thing. For quick viewing, download the file locally instead.

How do I run the meeting-minutes skill?

Drop a meeting transcript into Co-Work (or paste it), then ask Claude to run the meeting-minutes skill or just ask “Can you create meeting minutes for this?”. Claude will detect the transcript and handle the formatting, summaries, and action items. If you’re not sure which skill to use for a task, check Connectors & Skills for the full menu and examples of what each does.

Who do I contact for access or questions?

Jake is your person—reach out to jake@aptera.us for account issues, tool connections, technical setup, or anything this site doesn’t answer. He’s the one who sets up connectors, manages enterprise access, and knows the Aptera-specific quirks. If you find a mistake on the site or have ideas for what to cover, ping him too.
