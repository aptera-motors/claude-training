Four Confluence pages, documented and published in an afternoon

Richard · Engineering Co-Work ⏱ 1–2 days of writing and formatting

Richard asked Claude to document the full Launch ↔ Aptera data collaboration workflow. Working in Co-Work, Claude built four native Confluence pages, published them straight through the Atlassian connector, reparented the page tree so everything nested correctly, and added acronym decoders to each page. Richard reviewed and approved. What would have been one to two days of manual writing and Confluence formatting was done in an afternoon.

SharePoint mystery solved at 5pm

Jake · IT Chat ⏱ an evening of googling

An HTML file refused to run correctly when hosted on SharePoint, and 5pm was not the time for a deep dive into Microsoft’s content-type quirks. Claude diagnosed the problem in minutes, explained exactly why SharePoint was mangling the file, and suggested GitHub Pages as a cleaner hosting path. Laptop closed by 5:15. That’s a win.

This training site built itself

Jake · IT Code

The entire site you’re reading right now — every page, every component, the deploy pipeline, the search index — was built by Claude Code in an afternoon. Multiple AI agents wrote pages in parallel while Claude orchestrated the whole thing. Jake’s job was mostly telling it what he wanted and reviewing the output. The future is weird and we’re here for it.

Meeting minutes that write themselves

Jake · IT Co-Work ⏱ 45 min per meeting

Built a reusable Co-Work skill that takes a raw Teams transcript and outputs polished Confluence meeting minutes plus Jira action items — formatted, linked, and ready to publish — in about 2 minutes flat. Every meeting used to mean 45 minutes of cleanup after. Now it’s a paste and a click.
