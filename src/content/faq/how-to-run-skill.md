---
question: How do I run the meeting-minutes skill?
order: 9
---

Drop a meeting transcript into Co-Work (or paste it), then ask Claude to run the meeting-minutes skill or just ask "Can you create meeting minutes for this?". Claude will detect the transcript and handle the formatting, summaries, and action items. If you're not sure which skill to use for a task, check [Connectors & Skills](/claude-training/connectors/) for the full menu and examples of what each does.
