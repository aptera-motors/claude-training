We have plugins and connectors for the big tools—Slack, NetSuite, Jira, Salesforce, and more. To request a new connector or set one up, ping Jake at jake@aptera.us. He'll either plug it in directly or help you configure one if Aptera's tech stack supports it. Check [Connectors & Skills](/claude-training/connectors/) for the full list of what's already wired up.
