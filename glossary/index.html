Glossary

Plain-English definitions for all the AI jargon.

A C H L M O P R S T V

A

Agent

A Claude Agent is an autonomous assistant that can plan multi-step tasks, use tools, and iterate toward a goal without you babysitting every step. It’s like hiring someone to handle a project start-to-finish instead of asking for one thing at a time. Agents power Schedules, Routines, and the most powerful automations in Claude Code.

Agentic loop

An agentic loop is a system where Claude is given a goal, takes an action, evaluates the result, and feeds it back as the next input — repeating until the goal is met or a stop condition is hit. It’s the engine behind autonomous, multi-step work: you define the goal and the rules, then let it run.

AI

Artificial Intelligence—software that learns patterns from data and makes decisions or predictions without being explicitly told how. Claude is an AI. At Aptera, AI doesn’t replace engineers or designers; it clears away busywork so you can focus on the hard, interesting stuff.

Artifact

An artifact is any substantial output Claude creates—code, HTML pages, design systems, essays, spreadsheets—that’s big enough or standalone enough to live on its own. Claude renders artifacts in a side window in Chat mode so you can view, edit, and copy them without cluttering the conversation.

C

Claude

Claude is Anthropic’s AI assistant—the one you’re using right now at Aptera. It comes in four brain sizes (Haiku, Sonnet, Opus, and Fable) and works across Chat, Co-Work, and Code modes. It’s trained to be helpful, honest, and harmless—which means it’ll tell you when it’s unsure instead of making stuff up.

Claude Code

Claude Code is the CLI (command-line tool) that runs on your machine and gives Claude full access to your dev environment, files, and tools. It’s where you build automations, Schedules, Routines, and one-shot projects. Think of it as your AI coworker with direct access to your workbench.

Co-Work

Co-Work is Claude’s collaboration mode—you upload files or folders, and Claude reads them and helps you analyze, edit, or transform them. It’s safer than Code mode (Claude only sees what you grant access to) but more powerful than Chat (Claude can work with real documents). Perfect for cleaning data, drafting, or analyzing reports.

Compaction

Compaction is when Claude condenses the earlier part of a long conversation into a compact summary to free up space in the context window. It lets a long session keep going without overflowing — but it’s lossy, so save anything important to a document, memory, or skill before you compact.

Connector (MCP)

A Connector is a bridge that lets Claude talk to external tools like Slack, Jira, NetSuite, or Salesforce. It’s built on a standard called MCP (Model Context Protocol). Instead of copy-pasting data, you describe what you want and Claude queries the tool directly. At Aptera, connectors let Claude access your actual data.

Context window

The context window is how much text Claude can see at once, measured in tokens. It’s large — hundreds of thousands of tokens, varying by model — but finite. Think of it as short-term memory: paste a 100-page document and Claude can reference the whole thing. Because quality can dip as it fills, very long sessions may need compaction.

H

Hallucination

When Claude confidently states something false or makes up details it wasn’t given. It’s not lying on purpose—it’s pattern-matching gone wrong. If Claude invents a URL, statistic, or quote that sounds plausible, that’s a hallucination. Always verify important facts independently and don’t treat Claude as a primary source.

L

LLM

Large Language Model—an AI trained on vast amounts of text to predict what words come next. Claude is an LLM. It doesn’t “understand” in a human sense; it’s exceptionally good at pattern-matching and generating plausible continuations. That’s why it’s powerful but fallible.

M

Model

A model is a trained AI—in your case, Claude. The main models are Haiku (fast, small), Sonnet (balanced), Opus (deep reasoning), and Fable (the frontier model, also used to orchestrate the others). Each is trained the same way but with different sizes, so they trade off speed and cost for reasoning power. Choose based on the job.

O

OODA loop

OODA — Observe, Orient, Decide, Act — is a decision cycle from military strategist John Boyd. It’s a handy way to picture an agentic loop: Claude observes the current state, orients it against the goal, decides the next action, acts, then repeats. The advantage comes from the speed of the cycle, not any single step.

Orchestrator

An orchestrator is a capable model (often Fable) that plans a big job and spawns sub-agents — separate Claude instances, each on the cheapest model that fits the task — to do the actual work. Premium thinking up top, economy labor below. It’s how large, multi-step projects get done efficiently.

P

Project

A Project in Claude Code is a workspace—your folder with code, docs, and files that Claude reads from and edits. When you run Claude Code pointing at a project directory, it understands the full context: your codebase, dependencies, and everything in the folder tree. Projects keep Claude organized.

Prompt

A prompt is the instruction or question you give Claude. It can be a single sentence (“Write a poem”) or a long detailed brief with examples and context. Better prompts get better results. See Prompting 101 for how to write prompts that actually work.

R

Routine

A Routine is a scheduled, automated agent that runs on a cron schedule—like “every morning at 9am” or “every Friday”. It’s how you hand off recurring work: summarize yesterday’s logs, fetch sales data, generate reports, send slack updates. Routines run in the background if your machine is on and Claude Code is running.

S

Schedule

A Schedule is a one-time or recurring task you set up in Claude Code to run at a specific time or interval. It’s the automation layer: “Run this script at 2pm” or “Check the build status every 15 minutes.” Schedules and Routines are powered by agents, so Claude plans and iterates to complete the job.

Skill

A Skill is a specialized tool or capability Claude can use—like meeting-minutes, code-review, or deep-research. Some skills are built into Claude, others are custom to Aptera. Think of skills as superpowers: instead of asking Claude to manually do something, you invoke a skill and Claude orchestrates it end-to-end.

T

Token

A token is a chunk of text — roughly 3–4 characters or about ¾ of a word — that AI models read and write in. “Aptera builds solar cars” is about 6 tokens. You don’t need to count them, but they’re the unit your usage is measured in.

V

Vibe coding

Vibe coding is the art of describing what you want in loose, natural language and letting Claude handle the details. Instead of dictating exactly how to code something, you say what problem you’re solving and what vibe you want, then iterate on the result. It’s higher-level, faster, and often better than traditional step-by-step instructions.
